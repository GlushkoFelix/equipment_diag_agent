## 10. 结论

- 真实 DeepSeek 接线已完成：归因与报告均发起了实际 API 请求，具备超时（连接 2 s、单次 5 s）、1 次指数退避、`json_object` + Pydantic 校验、失败回落与日志脱敏；Key 仅从 `.env` 读取。
- KPI-01 按 `C-011` 主验收：五分类 **96.36%（106/110）≥90%**，**达标**（产品方 2026-10-25 批准）。
- 六分类原始值 **88.33%（106/120）** 仍如实披露且低于 90%；差额 2 条，全部来自 AI4I 标签机理噪声：4 条正常集磨损 ≥190、10 条 RNF。该值不再作为本次主验收依据，但不得隐去。
- 在“不放宽 RNF 兜底、不改 PRD 阈值、不让 LLM 覆盖规则证据”的约束下，本冻结集的诚实上限即为 106/120 = 88.33%；RNF 单列为 0/10，不计入主准确率分子分母。
- KPI-02、KPI-03、超时率、artifact 落盘达标；KPI-05 因评审口径未确认仍为 `null`，需单独立项，不阻塞 KPI-01。
- 本轮未重跑 KPI、未改评测集、未改 PRD 六分类门槛；C-011 仅登记本次交付的例外验收范围。
